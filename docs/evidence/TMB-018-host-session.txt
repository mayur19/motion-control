Automated test
--------------
Command:
  godot --headless --path apps/host-godot \
    --script res://tests/session_manager_test.gd \
    -- --output=docs/evidence/TMB-018-qr.png

The deterministic test proves:
- loopback, link-local and IPv6 addresses are not advertised;
- automatic selection prefers Wi-Fi over a VPN tunnel;
- explicitly selecting the VPN preserves a visible warning;
- every generated URI round-trips through strict parsing;
- expiry changes from valid to expired at the exact Unix-second boundary;
- session rotation replaces both the session ID and pairing secret;
- the manual code contains the complete ephemeral secret;
- the QR generator returns a square symbol with a four-module quiet zone.
